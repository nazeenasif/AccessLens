# Data Model: AccessLens MVP

**Feature**: `001-accesslens-mvp` | **Date**: 2026-10-21 (reconciled 2026-10-21)

All entities are defined once as Zod schemas in `packages/shared/src/schemas/`, and TypeScript
types are inferred from them. The OpenAPI contracts in [contracts/](./contracts/) mirror these
schemas; on any mismatch, this document and the Zod schemas win, and the contract is corrected.
**The server persists none of these entities**; they exist only in transit (NDJSON stream,
explain request/response) and in the developer's browser (IndexedDB).

## Entity overview

```text
Audit 1───* Finding 1───* AffectedNode
  │            ├──0..1 SignedEvidenceV1 + evidenceSignature   (violations only; created by web)
  │            └──0..1 AiAnnotation   (browser store, keyed by auditId+findingId)
  └── Comparison (derived on demand from two Audits; not stored)
ReportExport (derived on demand; downloaded, not stored)
DemoDataset = { audits: Audit[2], aiAnnotations: AiAnnotation[] }  (static, bundled)
```

## Audit outcome semantics (shared by spec, contracts, and UI)

An audit attempt ends in exactly one of three ways. The **scanner alone** decides which; AI
availability never affects it (spec FR-007a).

| Outcome | Stream terminal event | Audit object? | Saved locally? | UI state |
|---|---|---|---|---|
| **complete** | `result` with `audit.status = "complete"` | Yes | Yes | Results (or Empty when there are no violations) |
| **partial** | `result` with `audit.status = "partial"` and `partialReasons` non-empty | Yes | Yes, labelled partial | Partial results + coverage explanation per reason |
| **error** | `error` with an `ErrorCode` | **No** | No | Specific error state (blocked, timeout, unreachable, page returned an error, not a web page, limit, page too large, busy, rate-limited, disabled) |

"Failed" is not an audit status: an attempt without valid results is an `error` and produces no
Audit. The interruption → outcome mapping is in [research R5](./research.md).

## Audit

| Field | Type | Rules |
|---|---|---|
| `id` | string (UUID v4) | Generated by the web service per audit. |
| `submittedUrl` | string | Normalized URL as submitted (scheme added, fragment stripped). ≤ 2048 chars. |
| `finalUrl` | string | URL after redirects. ≤ 2048 chars. |
| `startedAt` / `completedAt` | RFC 3339 UTC string | `completedAt` ≥ `startedAt`. |
| `expiresAt` | RFC 3339 UTC string | **Browser only** (not in API payloads): set on save as `completedAt + 7 days` (FR-034). |
| `status` | `"complete" \| "partial"` | See outcome semantics. |
| `partialReasons` | `PartialReason[]` (unique) | Empty iff `status === "complete"`; non-empty iff `"partial"`. |
| `engine` | `{ name: "axe-core", version: string, tags: string[] }` | All required. `tags` = exactly the selected set in research R2. |
| `summary` | `{ critical, serious, moderate, minor, bestPractice, manualReview, passesCount }` | All required, integers ≥ 0. Severity counts cover `violation` findings (WCAG-mapped and best-practice); `bestPractice` is the subset of violations with `isBestPractice`; `manualReview` counts `manual_review` findings. Must equal counts recomputed from `findings` (tested). |
| `blockedRequests` | `{ count: integer ≥ 0, sampleHosts: string[0..5] }` | Both required. Hosts only, no paths/queries. |
| `limitations` | `string[]` | Coverage notes beyond partial reasons (e.g., "login page detected"). |
| `findings` | `Finding[]` | May be empty. |

**PartialReason** (fixed enum; each has a fixed user-facing coverage explanation in
`packages/shared/src/wording.ts`):

| Value | Meaning |
|---|---|
| `navigation_timeout` | The page document loaded, but the page didn't finish loading within the navigation time limit; content loaded later wasn't evaluated. |
| `request_limit_reached` | The per-audit request cap was reached; further resources weren't loaded. |
| `byte_limit_reached` | The per-audit byte cap was reached; further resources weren't loaded. |
| `frames_not_inspected` | One or more frames couldn't be tested (axe `frame-tested`). |
| `subresources_blocked` | One or more resources were blocked by the destination policy (FR-003). |

**Client view state**: `idle → validating → queued → loading → analyzing → complete | partial`,
or `→ error(code)` from any active state.

## Finding

| Field | Type | Rules |
|---|---|---|
| `id` | string (16 hex) | `sha256(kind + ":" + ruleId)` truncated; stable within and across audits. |
| `kind` | `"violation" \| "manual_review"` | `violation` ← axe `violations`; `manual_review` ← axe `incomplete`. Immutable. |
| `ruleId` | string | axe rule ID, verbatim. |
| `impact` | `"critical" \| "serious" \| "moderate" \| "minor" \| null` | Verbatim from axe. **Required non-null when `kind = "violation"`**; may be null only for `manual_review`. No code path modifies it after scan (constitution I). |
| `category` | string | From axe `cat.*` tag (e.g., `cat.color` → "Color & contrast"); `"Other"` if none. |
| `isBestPractice` | boolean | `true` iff tags include `best-practice` and no WCAG level tag (research R2). |
| `wcag` | `string[]` | Criteria parsed from `wcagNNN(N)` tags (e.g., `"1.4.3"`); empty → "not mapped". Always empty when `isBestPractice`. |
| `help` / `description` | string | Verbatim from axe. |
| `helpUrl` | string (https URL) | Verbatim from axe; rendered as a plain link. |
| `nodes` | `AffectedNode[1..25]` | Axe order; capped at 25. |
| `omittedNodeCount` | integer ≥ 0 | Nodes beyond the cap. |
| `evidence` | `SignedEvidenceV1` | **Present iff `kind = "violation"`** after the web service signs it; absent in scanner output. Stored verbatim in the browser; never reconstructed client-side. |
| `evidenceSignature` | string (base64url, 43 chars) | Present iff `evidence` is present. |

## AffectedNode

| Field | Type | Rules |
|---|---|---|
| `target` | `string[]` (≥ 1) | axe target selector path (handles iframes/shadow DOM). |
| `selector` | string | `target.join(" >>> ")`, used for display and comparison (not truncated here). |
| `html` | string (≤ 501) | axe `node.html`, truncated to 500 chars + "…". Untrusted: rendered only as text. |
| `failureSummary` | string (≤ 1001) | Truncated to 1000 chars + "…". Untrusted text. |

## SignedEvidenceV1 (violations only)

This is the exact set of values the AI prompt may use; full definition, canonical serialization,
reduction rule, and verification order are in [research R6](./research.md).

| Field | Type | Rules |
|---|---|---|
| `v` | `1` | Version; any other value is rejected. |
| `kid` | string (8 hex) | Signing-key id. |
| `auditId`, `findingId` | string | Identity binding. |
| `kind` | `"violation"` | — |
| `ruleId`, `impact` | as Finding | `impact` non-null. |
| `help` (≤ 500), `description` (≤ 1000) | string | Signed so the prompt never uses unsigned text. |
| `wcag` | `string[0..10]` | — |
| `isBestPractice` | boolean | — |
| `finalUrl` | string (≤ 2048) | URL context for the prompt. |
| `nodes` | `{ selector(≤500), html(≤501), failureSummary(≤1001) }[1..5]` | Deterministic server-side reduction from `Finding.nodes`; node text total ≤ 6 000 chars. |
| `nodesOmitted` | integer ≥ 0 | Nodes not included in the evidence. |
| `issuedAt` | RFC 3339 UTC, second precision | Valid for 7 days (60 s skew). |

## AiAnnotation (browser only)

| Field | Type | Rules |
|---|---|---|
| `auditId` + `findingId` | composite key | Must reference a stored Finding with `kind = "violation"`. |
| `status` | `"available" \| "unavailable" \| "rejected"` | `rejected` = failed validation (FR-017). Only `available` is persisted; others are in-memory and allow retry. |
| `explanation` | `{ summary(≤600), whoIsAffected(≤400), whyItMatters(≤600) }` | Present iff `available`. |
| `suggestedFix` | `{ language: "html"\|"css"\|"aria", code(≤2000), notes(≤600) }` | Present iff `available`. Inert text with an "Unverified suggestion" label. |
| `needsHumanJudgment` | boolean | Display-only; does not change `kind`. |
| `provider` / `model` | string | From config; shown in small print. |
| `generatedAt` | RFC 3339 UTC string | — |

AI annotations never change `Audit.status`, `partialReasons`, or any Finding field.

## Comparison (derived, not stored)

| Field | Type | Rules |
|---|---|---|
| `baselineAuditId` / `currentAuditId` | string | Baseline `completedAt` < current `completedAt`; both stored locally (FR-038). |
| `remaining` / `noLongerDetected` / `new` | `Occurrence[]` | Each occurrence is in exactly one list (SC-010). |
| `counts` | per list `{ total, bySeverity }` | — |
| `warnings` | `("final_url_differs" \| "partial_audit" \| "engine_version_differs")[]` | FR-025. |

**Occurrence** = `{ findingId, ruleId, kind, impact, selector }`; the matching key is
`kind|ruleId|selector`.

## Persistence (IndexedDB `accesslens`, version 1)

| Store | Key | Indexes | Notes |
|---|---|---|---|
| `audits` | `id` | `submittedUrl`, `expiresAt` | Full Audit object (complete or partial), including `evidence` and `evidenceSignature`. |
| `aiAnnotations` | `[auditId, findingId]` | `auditId` | Deleted together with their audit. |

**Purge**: on every app start, delete audits with `expiresAt <= now` together with their
annotations, in one transaction. "Clear history" deletes everything in the same way.
**Fallback**: if opening the DB or writing to it fails, use an in-memory Map and set
`historyAvailable = false` (FR-036).

## Validation rules traced to requirements

| Rule | Source |
|---|---|
| Findings/impact immutable after scan; AI output cannot set them | FR-010, FR-017, constitution I |
| `impact` non-null for violations | FR-010 |
| `manual_review` findings excluded from violation counts | FR-012 |
| Best-practice findings flagged and distinguishable; `wcag` empty | FR-010a |
| `partialReasons` non-empty iff partial; status set by scanner only | FR-007a |
| AI output must echo `findingId`/`ruleId`; strict schema | FR-017 |
| Evidence verified (MAC, `kid`, ≤ 7 days) before any prompt is built; prompt uses only signed values | FR-022a |
| Snippet/summary truncation; no full HTML stored | FR-032 |
| `expiresAt = completedAt + 7d`; purge on load | FR-034 |
